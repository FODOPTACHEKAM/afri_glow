# 1. Project Submitted — 5 Marks

## Overview
AfriGlow is a fully submitted Flutter mobile application developed for the OOADI 11 course. The project was built from scratch and covers the complete development lifecycle from requirements gathering to a deployable release.

## What Was Submitted

- **Flutter Application** — `flutter_application_skin_wise/` containing all Dart source code, assets, and configuration files.
- **Website** — `AfriGlow_Website/` with a live-ready landing page (HTML/CSS/JS) presenting the app for public download.
- **Release APK** — A signed Android release APK (`app-release.apk`, 66.2 MB) built with `flutter build apk --release`, package `com.afriglow.skinwise`.
- **Firebase Backend** — Firestore database, Firebase Authentication (Email/Password + Google Sign-In), and security rules deployed to `afriglow-skinwise` Firebase project.
- **Documentation** — AfriGlow Final Report, VPS Deployment Guide, and project documents submitted alongside the codebase.
- **Source Control** — Code maintained on GitHub at `https://github.com/FODOPTACHEKAM/afri_glow`.
